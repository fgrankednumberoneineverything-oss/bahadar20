# بهادار — محاسبه دقیق، سود بیشتر

برنامه‌ی اندرویدی آفلاین برای **بهای تمام‌شده، انبار، خرید و فروش و حسابداری مالی**، ادغام‌شده از دو شاخه‌ی پروژه:

| از | آنچه آمد |
|---|---|
| فاز ۶ (`app.js`) | اسناد حسابداری، دفتر روزنامه/کل، تراز، سود و زیان، ABC، سناریو، چندارزی، سرور Supabase و همگام‌سازی |
| نسخه ۰٫۵ (`ext-*.js`) | داشبورد، MRP، برنامه خرید، چک‌ها، اشخاص، لیست قیمت، گاوصندوق رمزنگاری‌شده، مجوز و ابزار مالک، انگلیسی، دسترس‌پذیری، راهنما |
| پوشه ۱ و ۱۱۱۱۱۱۱ | مغایرت‌گیری اسناد و خروجی Excel «روزنامه + دفتر کل + تراز» (در منوی عملیات) |
| `bahadar-ui` | نام و برند «بهادار»، پالت سرمه‌ای/فیروزه‌ای/طلایی، اسپلش متحرک، نوار پایین شناور، آیکون جدید |

## ساخت APK
1. همه‌ی محتوای این پوشه را در یک مخزن GitHub بگذارید و Commit کنید.
2. در Actions منتظر سبز شدن «ساخت APK بهادار» بمانید و `bahadar-apk` را دانلود کنید.
3. `appId` همان `ir.hesabdar.baha` است؛ اگر با همان کلید امضا شود، روی نسخه‌ی قبلی «به‌روزرسانی» می‌شود. **پیش از نصب پشتیبان بگیرید.**

## سرور (اختیاری)
راهنمای Supabase در `server_setup.sql` و بخش «همگام‌سازی» برنامه آمده است. برنامه بدون سرور هم کامل کار می‌کند.

## پوشه `android-native-ui`
پوسته‌ی بومی Kotlin/Compose (اسپلش و صفحه‌ی اصلی) برای پروژه‌ی بومی جداگانه. برنامه‌ی وب بالا به آن نیاز ندارد.

## آزموده شد / نشد
- آزموده (Chromium بدون‌سر): ورود و راه‌اندازی، هر ۳۲ صفحه‌ی عملیات بدون خطای جاوااسکریپت، تم تیره و روشن، اسپلش، مغایرت‌گیری تا اصلاح (تشخیص ← ابطال و ثبت سند اصلاحی ← بررسی دوباره).
- **آزموده نشد:** خروجی Excel (ExcelJS در این محیط نبود؛ هنگام ساخت نصب می‌شود)، نصب APK روی گوشی، سرور Supabase واقعی، TalkBack.
- بدون کلید امضای release؛ نسخه هنوز debug است.

## ورود اطلاعات شرکت «دوغ آبعلی»
فایل `www/import-company.js` و داده‌ی `www/doogh-abali.json` اضافه شده‌اند. در بخش «پشتیبان» دکمه‌ی «افزودن شرکت دوغ آبعلی» (یا انتخاب فایل JSON دیگر) دیده می‌شود. ورود فقط یک شرکت جدید می‌سازد و داده‌های موجود را تغییر نمی‌دهد.
